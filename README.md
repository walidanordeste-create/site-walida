## 🔒 Segurança

### Headers de Segurança
- **Content-Security-Policy (CSP)** — Proteção contra XSS
- **X-UA-Compatible** — Compatibilidade com navegadores antigos
- **Referrer Policy** — Controle de dados de referência
- **HTTPS** — Obrigatório via GitHub Pages

### Arquivos de Configuração
- **`.nojekyll`** — Desabilita Jekyll processing
- **`_config.yml`** — Configuração segura do GitHub Pages
- **`robots.txt`** — Instruções para bots de busca

## 🚀 Como Atualizar

### Fazer mudanças

```bash
git clone https://github.com/walidanordeste-create/site-walida.git
cd site-walida
# Editar index.html ou outros arquivos
git add .
git commit -m "Descrição da mudança"
git push origin main
```

1. Acesse: https://search.google.com/search-console

3. Verifique usando o arquivo HTML já incluído: `google368eb4997d929ee5.html`
4. Solicite indexação do sitemap
